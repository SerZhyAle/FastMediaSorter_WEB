FastMediaSorter for Web

Сортировщик медиа в браузере

Просматривайте, сортируйте и обменивайтесь медиа в браузере.

FastMediaSorter for Web приносит просмотр, воспроизведение, быструю сортировку по папкам и доступ к Media Exchange Server в браузер для систем, где не работают нативные программы.

Для macOS, Linux, ChromeOS, iOS, iPadOS и всех, кто не может установить нативную программу.

Просмотр и воспроизведение локальных медиа

Откройте локальную папку в браузере, чтобы смотреть фото и анимацию, воспроизводить видео и аудио и запускать слайд-шоу с удержанием экрана.

Сортировка по папкам назначения

Выберите до десяти папок назначения и нажимайте 1-9 или 0, чтобы переместить открытый файл и перейти к следующему. Файлы с тем же именем не перезаписываются.

Перемещение файлов в папки назначения работает в Chrome и Edge на компьютере; в остальных браузерах элемент остаётся видимым и отключённым с указанием причины.

Учётная запись обмена и буфер

Подключите браузер как ещё одно устройство к Media Exchange Server: регистрируйтесь по приглашению, смотрите устройства и папки, принимайте трансляции и используйте общий буфер.

Администрирование сервера и диагностика

Управляйте сервером Media Exchange Server из браузера и сохраняйте локальный ZIP-отчёт диагностики без имён файлов, паролей и ключей.

Начало работы

  1. Скачайте последний релизный архив в GitHub Releases или раздавайте статическую папку web/ с вашего Media Exchange Server (webDir) либо любого статического HTTPS-хостинга.
  2. Откройте приложение в Chrome, Edge, Firefox, Safari или Samsung Internet.
  3. Выберите локальную папку для просмотра и сортировки или откройте ссылку-приглашение для входа в учётную запись обмена.

Возможности и совместимость

01Локальные медиа, сортировка и слайд-шоу

Открывайте папки с изображениями, анимацией, видео и аудио прямо в браузере. Запускайте слайд-шоу с удержанием экрана там, где поддерживается Wake Lock.

В Chrome и Edge на компьютере выберите до десяти папок назначения и сортируйте файлы клавишами 1-9 и 0.

02Учётная запись обмена и Media Exchange Server

Браузер работает по общему протоколу DEVICE-EXCHANGE. Закрытый ключ устройства никогда не покидает браузер, а сервер не может прочитать зашифрованное содержимое. Подключение учётной записи обмена - не то же самое, что локальная раздача папок по SFTP в программе для Windows: учётная запись живет на Media Exchange Server, который держит его владелец, у браузера нет своего SFTP, и для работы этого веб-приложения не нужна никакая установка на Windows.

Подробнее на общем портале Обмен медиа между устройствами и странице Media Exchange Server.

04Нативные программы семейства

Функции, требующие самой операционной системы - прослушивание порта, работа после закрытия вкладки, прямые сокеты или связь с часами - остаются в нативных программах: Fast Media Sorter & Organizer (Android) и Fast Media Sorter & Sharing for Windows (Windows) - Медиа- и файловый менеджер для Windows: сортировка фото и видео одной клавишей. Она ставится как четыре необязательные части - медиа- и файловый менеджер, локальная раздача папок по SFTP, операции с файлами по расписанию и Media Exchange Server, который вы держите сами - начиная с менеджера или с сервера раздачи папок, и ни одной из них не нужна другая; сервер обмена не входит ни в один опубликованный пакет, и для работы этого веб-приложения не нужна никакая установка на Windows. Свою страницу с вариантами установки называет сама программа для Windows.
