Приватность и разрешения браузера

FastMediaSorter for Web работает локально в вашем браузере без телеметрии, аналитики и рекламы.

Разрешения браузера

  • Чтение локальной папки (showDirectoryPicker, режим чтения): запрашивается только при выборе папки для просмотра.
  • Перемещение в папки назначения (showDirectoryPicker, режим чтения и записи): запрашивается в Chrome и Edge на компьютере только при выборе папок сортировки.
  • Буфер обмена (navigator.clipboard.writeText): используется только при нажатии кнопки копирования.
  • Удержание экрана (navigator.wakeLock): запрашивается только во время работы слайд-шоу.
  • Локальное хранилище (localStorage): хранит язык интерфейса, тему, настройки и список папок назначения на этом устройстве.

Сетевые адреса

  • Страница продукта и режим локальных файлов не выполняют сторонних сетевых запросов.
  • При подключении учётной записи обмена браузер общается по HTTPS/WSS только с тем адресом Media Exchange Server, который вы ввели или открыли из приглашения.
  • Закрытый ключ устройства остаётся в браузере и никогда не отправляется на сервер, не попадает в журнал и экспорт.

Отчёт диагностики

  • Экран «О программе» может создать локальный ZIP-архив диагностики по вашему нажатию. В нём содержатся сведения о возможностях браузера, настройках и журнале текущего визита, без имён файлов, папок, паролей, токенов и ключей.
