FastMediaSorter for Web

Browser media sorter

Browse, sort and exchange media in your browser.

FastMediaSorter for Web brings browsing, playback, quick folder sorting and Media Exchange Server access to your browser on systems where the native programs do not run.

Built for macOS, Linux, ChromeOS, iOS, iPadOS and anyone who cannot install a native program.

Browse and play local media

Open a local folder in your browser to view photos and animated images, play video and audio, and run a slideshow with Screen Wake Lock.

Sort into destination folders

Assign up to ten destination folders and press 1 to 9 or 0 to move the open file and advance to the next one. Same-name files are never overwritten.

Moving files to destination folders works in Chrome and Edge on desktop; in other browsers the control stays visible and disabled with the reason beside it.

Exchange account and clipboard

Join your account as one more device on a Media Exchange Server: register from an invitation link, view devices and folders, receive broadcasts and share the clipboard.

Server administration and diagnostics

Run Media Exchange Server administration from the browser and export a local diagnostic ZIP report on request with no file names, passwords or keys.

Get started

  1. Open the latest release bundle from GitHub Releases or serve the static web/ folder from your Media Exchange Server (webDir) or any HTTPS static host.
  2. Open the app in Chrome, Edge, Firefox, Safari or Samsung Internet.
  3. Choose a local folder to browse and sort, or paste an invitation link to connect to your exchange account.

Features and compatibility

01Local media, sorting and slideshow

Open any folder of images, animated images, video or audio directly in the browser. Run a timed slideshow while keeping the screen awake where Wake Lock is supported.

In Chrome and Edge on desktop, select up to ten destination folders and sort files with keys 1 to 9 and 0.

02Exchange account and Media Exchange Server

The browser speaks the shared DEVICE-EXCHANGE protocol. Your device private key never leaves the browser, and sealed content cannot be read by the server. Connecting an exchange account is distinct from installing the Windows program's local SFTP folder sharing: the account lives on a Media Exchange Server that its owner runs, the browser has no SFTP of its own, and no Windows installation is required to use this web app.

Read more on the shared Media exchange between your devices portal and the Media Exchange Server page.

04Native family programs

Functions that require the operating system itself - listening on a port, running after the tab closes, raw sockets or watch pairing - stay with the native programs: Fast Media Sorter & Organizer (Android) and Fast Media Sorter & Sharing for Windows (Windows) - Media and file manager for Windows: sort photos and videos with one key. It installs as four optional parts - a media and file manager, local SFTP folder sharing, scheduled file operations and a Media Exchange Server you run yourself - starting with the manager or with the folder-sharing server, neither needing the other; the exchange server is not in any published package, and no Windows installation is required to use this web app. The Windows program's own page names its install choices.
