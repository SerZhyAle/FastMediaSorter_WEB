Privacy and browser permissions

FastMediaSorter for Web runs locally in your browser with no telemetry, no analytics and no advertising.

Browser permissions

  • Read local folder (showDirectoryPicker read mode): requested only when you choose a folder to browse.
  • Move to destination folders (showDirectoryPicker readwrite mode): requested on Chrome and Edge desktop only when you bind destination folders for sorting.
  • Clipboard (navigator.clipboard.writeText): used only when you press a copy button.
  • Screen Wake Lock (navigator.wakeLock): requested only while a slideshow is running.
  • Local storage (localStorage): stores your interface language, theme, preferences and destination folder list on this device.

Network addresses

  • The product site and local media mode make no third-party network requests.
  • When you connect an exchange account, the browser communicates over HTTPS/WSS exclusively with the Media Exchange Server address you entered or opened from an invitation.
  • Your device private key stays inside the browser and is never sent to the server, logged or exported.

Diagnostic report

  • The About screen can create a local diagnostic ZIP archive on request. It contains browser capabilities, page settings and the current visit log, with no file names, folder names, passwords, tokens or private keys.
